# 纪律型而非手册型

现有 jj skill 以命令语法和 git 对照表为主体。语法会随 jj 版本过期，过期的语法表正是 agent 幻觉旧命令的来源之一。本 skill 只规定**纪律**——何时做什么、做完如何验证、出事如何恢复——语法留给环境（`jj help`）。

唯一的例外是**危险面**：哪些命令会在非交互环境挂死、哪些会 exit 0 却什么都没做。这些 `--help` 不会招认（实测 `jj split --help` 自称 "Starts a diff editor"，却不说给了路径仍会开 `$EDITOR` 并挂死），所以必须在正文缓存。

事实底稿以本机二进制实测为准（`.scratch/facts/jj-0.44-cli.md`，jj 0.44.0），不信预训练记忆，不信网上教程。
